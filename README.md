# Stone Memory

Stone Memory 官网静态发布文件。

- 项目：https://github.com/wanyu445/stone_memory
- 官网：https://stonememory.github.io/
- 使用 GitHub Pages 默认 HTTPS 地址，不绑定自定义域名。
- 发布方式：GitHub Pages，`main` 分支根目录。
- `index.html` 内嵌网页样式、脚本、字体和图片，无需 Node 服务。
- 项目许可见 `LICENSE`，字体许可见 `licenses/`。

此仓库仅包含已脱敏的官网发布快照，不含产品数据库、部署凭据或私有开发历史。

## 页面内容

记忆摘要、长期整理、线程重建、依据回查、本地部署与琢石坊。重建步骤和插件展示为浏览器内的交互说明，不执行产品后台操作。

琢石坊展示公开产品仓库中的八个注册模块：主题笔记、自动织梦、刮刮乐、拓展挖掘台、连续性实验室、Stone Memory 小助理、前端工作台、琢石坊协作社区。另有独立的 DIY 制作台介绍，说明从想法、开发工单到 Agent 编写并按模块规范接入的路径。
